## Dokumentasi Core

### Service

* **core/src/service.js**: File ini berisi fungsi untuk memuat semua service modules dari direktori yang ditentukan.

### Controller

* **core/src/controller.js**: File ini berisi fungsi untuk memuat semua controller modules dari direktori yang ditentukan.

### Model

* **core/src/model.js**: File ini berisi fungsi untuk memuat semua model modules dari direktori yang ditentukan.

### Repository

* **core/src/repository.js**: File ini berisi fungsi untuk memuat semua repository modules dari direktori yang ditentukan.

### Exceptions

* **core/src/exceptions/error.exception.js**: File ini berisi definisi kelas AppErrorWithCapture yang digunakan untuk menangani error.

### Utils

* **core/src/utils/formatter.js**: File ini berisi fungsi untuk memformat tanggal dan string.

### Plasgos

* **core/src/plasgos.js**: File ini berisi fungsi untuk memuat semua modul yang dibutuhkan oleh aplikasi.
